# ბილიარდას თავგადასავალი (Biliarda's Quest) 🎮

ინტერაქტიული იუმორისტული საიტი / მინი-თამაში, შექმნილი სპეციალურად GitHub Pages-ზე განსათავსებლად.

## 🚀 როგორ გავუშვათ GitHub Pages-ზე 1 წუთში:

1. გახსენით თქვენი GitHub და შექმენით ახალი რეპოზიტორი (მაგ. `biliarda`).
2. ატვირთეთ ფაილები (`index.html`, `style.css`, `script.js` და ფოტოები).
   - **შენიშვნა სურათებზე**: სურათები უკვე პირდაპირ კოდშია ჩაშენებული (Base64), ამიტომ `assets` საქაღალდეც რომ დაგავიწყდეთ, საიტი მაინც 100%-ით აჩვენებს ყველა ფოტოს ნებისმიერ ვითარებაში!
3. შედით რეპოზიტორის **Settings** -> **Pages** მენიუში.
4. **Branch** ველში აირჩიეთ `main` (ან `master`), საქაღალდედ დატოვეთ `/ (root)` და დააჭირეთ **Save**.
5. 10-20 წამში თქვენი საიტი მზად იქნება და მოგცემთ ბმულს (მაგ: `https://username.github.io/biliarda/`).
